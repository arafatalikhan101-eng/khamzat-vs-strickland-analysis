# khamzat-vs-strickland-analysis
Data-driven fight analysis using Python and visualization

This project analyzes the fighting styles of Khamzat Chimaev and Sean Strickland using Python and data visualization.

## Objective
To understand performance patterns and compare strengths like striking, grappling, and finishing ability.

## Key Insights
- Chimaev shows strong early dominance with high finishing ability
- Higher striking output suggests aggressive pressure
- Grappling control is a major advantage
- Fight dynamic: **Control vs Endurance**

## Tools Used
- Python (pandas, matplotlib)
- Data visualization
- Presentation design

## Files
- Jupyter Notebook (.ipynb)
- Presentation (.pdf)
